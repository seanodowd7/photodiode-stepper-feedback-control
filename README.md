# photodiode-stepper-feedback-control
Built a small photodiode feedback control system that received input from a laser and moved a stepper accordingly

Hardware used:

Arduino UNO R4 WiFi
28BYJ-48 5V stepper motor
ULN2003 stepper motor driver board
BPW34 photodiode
4.7 kΩ resistor
650 nm red laser module
Breadboard
Breadboard power supply / 5V power source
Jumper wires
Paper, used to simulate the moving fuel surface
USB cable, for programming and powering the Arduino
